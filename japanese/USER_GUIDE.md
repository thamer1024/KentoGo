## KentoGo を使う最初の日

KaTrain とその KataGo（KentoGo も同じ KataGo を使います）と、自分の対局の SGF ファイルが
いくつか必要です。そのうえで：

1. **KentoGo を起動します。** 最初の起動では、KataGo とモデルの場所を KaTrain の設定から
   写します。KataGo の読み込み中はダイアログが出ます。閉じて先に進んでかまいません。
2. **棋譜の場所と、自分の名前を設定します。** ☰ > 「一般・エンジン設定」を開きます：
   - 「棋譜フォルダ」：SGF ファイルのあるフォルダ。
   - 「自分の名前（カンマ区切り）」：対局で使っている名前（囲碁サーバーでの名前など）。
     KentoGo はこれで自分の色を見分けます。KaTrain で AI と打った棋譜は名前がなくても分かりますが、
     囲碁サーバーの棋譜には必要です。
   「設定を更新」を押します。
3. **KataGo をパソコンに合わせます。** ☰ > 「推奨設定」を開き、使っているパソコンの種類を選んで
   「設定」を押します。分からないときは「測る」を押すと、KataGo の速さを測って値を決めます。
   （それでも遅いときは「KentoGo が遅いとき」を見てください。）
4. **棋譜を解析します。** トップ画面の「KataGoで棋譜解析」を押し、チェックの付いた棋譜のまま
   「選んだ N 局を解析」を押します。1局約2分です。KaTrain で解析済みの棋譜もそのまま使えますが、
   局地戦の問題が出るのは KentoGo で解析した棋譜だけです。
5. **最初の問題を解きます。** トップ画面に戻り、「悪手問題」を押してから「始める」を押します。
6. **局地戦も試します。** トップ画面の「局地戦の問題（生き死に・境界）」を押します。

「悪手問題」で問題がないと言われたら、最初の画面の「出題できない棋譜を見る」を押してください。
棋譜ごとに理由（解析されていない、名前が「自分の名前」にない、など）が出ます。

## 毎日の練習

KentoGo は、毎日少しずつ練習するように作ってあります。たとえば次のような一日です：

1. 何局か打ったら、棋譜フォルダに入れて解析します（「KataGoで棋譜解析」）。
2. 今日の悪手問題を解きます（最初は1日20問まで）。間違えた問題は次の日にまた出ます。正解した問題も、
   2回続けて正解するまで、何日か空けてまた出ます。
3. 今日の局地戦を打ちます（最初は1日5問まで）。
4. トップ画面に戻ると、「今日のまとめ」にその日の結果が出ます。ときどき「成績表」を開くと、
   日ごとの伸びが分かります。

1日の上限は午前0時にリセットされます。その日の問題が終わると、そう表示されます。

## 悪手問題

自分の対局で大きく損をした手が問題になります。打った手よりよい手を見つけてください。

### 最初の画面

KentoGo は棋譜フォルダの棋譜を読み、今日の新しい問題と復習の数、今日あと何問出せるかを表示します。
段階出題のときは、今の段階も表示します。「始める」（または Enter）を押します。

「出題できない棋譜を見る」は、問題が見つからなかった棋譜を、理由と一緒に一覧にします。

### 問題を解く

1. 盤には、悪手を打つ直前の局面が出ます。考えて、打つ場所をクリックします。
2. KataGo が答えを判定します。正解かどうか、答えの損、実戦の手の損、その損のうち取り戻した割合が
   表示されます。
3. 答えのあとの手順（下を参照）を見て、理由を確かめます。それから「次の問題」（または Enter）を
   押します。

「次の問題」は、KataGo がまだ読んでいる間でもいつでも押せます。
「この棋譜を見る」は、問題の棋譜をその手のところで「棋譜を見る」画面に開きます。

**正解になるのは？** 手短に言うと、実戦の手の損のうち、かなりの部分（最初は60%）を取り戻せば
正解です。小さい問題（実戦の手の損が3目未満）では、実戦の手より損をしなければ正解です。損が1目
以内の答えは、いつも正解です。値は変えられます（「判定設定」を参照）。

### 答えのあとの手順

| キー | 動き |
| --- | --- |
| Tab | 次の手順に切り替える |
| Shift+Tab | 前の手順に切り替える |
| → または Space | 手順を1手進める |
| ← または Shift+Space | 手順を1手戻す |
| Enter | 次の問題 |

「◀ 戻る」「進む ▶」「手順を切り替え（Tab）」のボタンも同じ動きです。切り替えると、手順の名前が
少しの間盤に出て、最初の手が打たれます。

手順は、Tab の順に次の3つです：

1. **段級位の応手**：答えのあと、自分は自分の段級位の手を、相手は相手の段級位の手を打ちます
   （KataGo の人間風モデル）。自分と同じくらいの棋力どうしで、答えのあと対局がどう進むかが分かります。
2. **実戦**：実戦で打った手と、そのあとに打たれた手。
3. **この局面の最善手**：問題の局面から、自分は自分の段級位の人が打ちそうな手のうち最もよい手を、
   相手は相手の段級位の手を打ちます。自分の手が届く範囲のよい手が分かります。

手順の一番新しい手はマゼンタの丸で、それより前の手には数字が付きます。盤には表示中の手での地が
出て、右側にはおおよその形勢が出ます。手順の最後の手では、正確な形勢が出ます。「段級位の応手」と
「この局面の最善手」では、同じ手数の実戦とも比べます（取り戻した目数）。

自分の段級位は棋譜（`BR`/`WR`）から、なければ AI 解説のときに入れた段級位から取ります。
どちらの段級位も分からないときは、両方とも KataGo の最善手を打ちます。

### 判定の変更の提案

ある程度答えると、KentoGo が合格ラインを上げるか下げるか、正解とする答えの損の上限を設けるか
下げるかを聞いてくることがあります。「はい」で設定を変え、「いいえ（今のまま）」でそのままにします。
強くなるにつれて KentoGo が判定を厳しくしていくので、自分で変える必要はありません。

### 今日のまとめ

その日に答えてからトップ画面に戻ると、「今日のまとめ」に、解いた問題と正解の数、取り戻した目数、
何日目の練習か、達成したこと、今ある問題の全体・完了・実施中・手付かずの件数が出ます。対象外にした
問題は数えません。棋譜から作られなくなった問題の復習は、実施中として数えます。

## 局地戦の問題

KentoGo で棋譜を解析すると、負けた生き死にの戦いと境界が見つかり、問題になります。戦いが始まった
局面から、KataGo と打ち直します。打つには KataGo が必要です。

1. 盤には、戦いが始まった局面が出ます。右側には、練習の種類（生き死に、または境界）と手番が出ます。
2. 打つ場所をクリックすると、KataGo が盤上で応じます。戦いの判定が出るまで続けます。
3. 「次の問題」（または Enter）はいつでも押せます。

戦いに勝ち、最初の局面からの目数の減りが許容する目数（最初は3目）以内なら正解です。戦いに負けた
とき、目数が減りすぎたとき、戦いから手を抜いたりパスしたりしたとき、打たなくてもよい手で損をした
ときは不正解です。**コツ：** 決着がつくまで戦いから離れないこと。ただし、もう安全な場所に手を
加えないこと。KataGo が手を抜いたら、その場所は決着がついたという合図です。

戦いのあと：

| キー | 動き |
| --- | --- |
| Tab | AI 同士の手順を出す。二つあるときは切り替える |
| → | 1手進める |
| ← | 1手戻す |
| Enter | 次の問題 |

AI 同士の手順では、戦いが始まった局面から、その場所の決着がつくまで両者が人間風の手を打ちます
（段級位が分からないときは9段）。ふつうはどう打たれるかが分かります。それで決着がつかないときは、
KataGo の最善手でも打ち直します。追いかけている石は、取られるか逃げ切るまで続けます。KataGo が
手順を作っている間は考えている秒数が出ます。時間がかかりすぎた手順は、そこで打ち切ります。

局地戦の中の自分の悪手は、悪手問題には出さず、局地戦の問題として出します。

その日に答えてからトップ画面に戻ると、「今日のまとめ」に、解いた問題と正解の数、今ある局地戦の
全体・完了・実施中・手付かずの件数が出ます。

## 棋譜を見る

「棋譜を選ぶ」を押して棋譜を選びます（「AI解説のある棋譜だけ」で一覧を絞れます）。

| キー | 動き |
| --- | --- |
| ← →（または Shift+Space、Space） | 1手戻る・進む |
| ↑ ↓ | AI 解説のある前・次の手 |
| Home / End | 最初・最後の手 |
| Tab / Shift+Tab | 解析の最善手順、ほかの分岐、本譜の順に出す |
| Esc | 本譜に戻る |
| T | 地と形勢の表示を切り替える |

右側には、手数、その手の損と最善手、AI 解説、自分のメモが出ます。スライダーで棋譜の中を動けます。
「総評」は、AI による対局全体の総評を出します。

## 整地練習

先に、☰ > 「一般・エンジン設定」の「整地練習も使う（トップ画面にボタンを出す）」をオンにします。
それからトップ画面の「整地練習」を押します。自分の対局の終局図を、日本ルールで整地します。

1. 死に石をクリックします（つながった石はまとめて死に石になります。もう一度クリックで元に戻ります）。
2. 「死に石を取り除く（アゲハマにする）」を押すか、盤の外へドラッグします。
3. ダメをクリックして石で埋めます（もう一度クリックで石を戻します）。
4. 「終局を確認して整地に入る」を押します。
5. 地を整えます。石を空いた点へドラッグする、相手の色の石の上に落として入れ替える、盤の下の
   アゲハマを同じ色の地へドラッグする、ができます。持ち主がはっきりしなくなった空き点は、
   クリックで決められます。
6. 「整地終了」を押して、数えた結果を確かめます。
7. 「できた」か「できなかった」を押します。できなかった棋譜は、後日また出ます。

「コンピュータの整地を見る」は、コンピュータの手順を再生します（参考用）。「▶ 自動再生」「■ 停止」と
← → キーで手順を見られます。「一つ戻す」は最後の操作を取り消し、「終局図に戻す」は最初からやり直します。

## KataGo で棋譜解析

1. 棋譜フォルダの棋譜が一覧になります。まだ解析していない棋譜にはチェックが付いています。
   「KentoGoで解析済みの棋譜も表示する」で、解析し直すために解析済みの棋譜も出せます。
   「すべて選ぶ」「すべて外す」でチェックをまとめて変えられます。
2. 「選んだ N 局を解析」を押します。棋譜ごとに進み具合が出ます。「中止」すると、解析中の棋譜が
   終わったところで止まります。

書き込む前に、棋譜はバックアップ先に写されます。推奨設定で1局約2分です。たくさんの棋譜をまとめて
解析し、ほかのことをしている間に進めておけます。

## AI で棋譜解析

Claude や ChatGPT などの AI が、なぜその手が悪手だったのかを言葉で説明します。3つの方法から選びます：

- **貼り付けモード（1局ずつ。API キー不要）**：棋譜と自分の色を選び、「プロンプトを作る」、
  「コピー」を押します。プロンプトを好きな AI のチャットに貼り、AI の答えを「AIの回答（ここに
  貼り付けてください）」に貼り戻して「反映」を押します。解説が棋譜に書き込まれます。
- **APIモード（1局ずつ）**：KentoGo が API キーで AI に直接聞きます（下の「AI解説設定」を参照）。
  棋譜と自分の色を選び、「AIに解説させる」を押します。
- **APIモード（新しい棋譜をまとめて）**：前回から変わった棋譜が一覧になります（最初は日付を選びます）。
  棋譜にチェックを付け、「AIに解説させる」を押します。「除外」で一覧から外せます。

AI が説明するには、棋譜が（KaTrain か KentoGo で）解析されている必要があります。すでに解説のある
棋譜は、確認してから置き換えます。解説は「棋譜を見る」で読めます。

## 成績表

成績表は練習した日で数えるので、練習しなかった日があっても数字は下がりません。

- **悪手問題**：解いた・正解した・完了した問題の数、取り戻した目数、練習した日数、最近5回の練習と
  その前の5回の比較。グラフは練習した日ごとの正答率と平均の取り戻し率で、点線が合格ラインです。
- **局地戦の問題**：目数を除いた同じ数と、正答率のグラフ。
- **対局ごとの悪手の数**：自分の手をすべて損の大きさで数え、直近5局の平均をその前の5局と比べます。
  対局を重ねて大きな悪手が減っていれば、練習の効果が出ています。

グラフは、練習した日または対局を最大14まで出します。

## 設定

設定は ☰ メニューから開きます。「設定を更新」を押すと保存され、すぐに使われます。棋譜フォルダや
出題の条件を変えると、次に悪手問題を始めるときに、すべての棋譜を読み直します（先に確認します）。

下の表では、各設定の働きと、変えると何が変わるかを説明します。

### 一般・エンジン設定

**KataGo設定**

ふつうは KaTrain から写されます。KataGo を起動できないときだけ変えてください。

| 設定 | 働き |
| --- | --- |
| KaTrainの設定ファイル（config.json） | KaTrain の設定の場所（`~/.katrain/config.json`）。「KaTrainから読み込む」で、KataGo の場所とエンジンの値をもう一度写します。 |
| KaTrainのプログラムフォルダ | `katrain/` で始まる場所に使う、KaTrain のプログラムのフォルダ（空欄なら自動で探す）。KataGo が見つからないと言われたら設定します。 |
| KataGo実行ファイル（フルパス） | KataGo のプログラム（空欄なら PATH にあるもの、または KaTrain に付いているもの）。 |
| KataGoモデルファイルの場所 | すべての読みに使うモデル。小さいモデル（b18c384nbt など）は速く、大きいモデル（b28c512nbt）は強いです。Mac では b28c512nbt か b18c384nbt を使ってください。変えたら「測る」を押します。 |
| 人間らしいモデルのパス | 段級位の応手と AI 同士の手順に使う、KataGo の人間風モデル（空欄なら使わない）。 |
| KataGo設定ファイルの場所 | KataGo の解析設定ファイル（KaTrain の `analysis_config.cfg`）。 |

**一般設定**

| 設定 | 働き |
| --- | --- |
| 棋譜フォルダ | SGF ファイルのフォルダ（空欄なら KentoGo の `games` フォルダ）。 |
| 自分の名前（カンマ区切り） | 対局で使っている名前。自分の色を見分けます。囲碁サーバーで使っている名前はすべて入れてください。ないと、その棋譜から問題が出ないことがあります。 |
| 整地練習も使う（トップ画面にボタンを出す） | トップ画面に「整地練習」を出す（オフ）。 |

**エンジン設定**

| 設定 | 働き | 変えると |
| --- | --- | --- |
| KataGoで計算する | SGF ファイルに損がない答えを KataGo で判定する（オン）。 | オフにすると、解析で読んである答えしか判定できません。オンのままにしてください。 |
| 分析時の最大探索手数 | 答えの判定と、局地戦の1手ごとに KataGo が読む局面の数（500）。 | 増やすと正確になりますが、1問ごとに時間がかかります。減らすと速くなりますが、判定が粗くなります。時間は探索手数にほぼ比例します。 |
| Wide root noise | KataGo がより多くの候補手を見るようにする（0.04。KaTrain と同じ）。 | そのままにしてください。 |
| 分析の最大時間（秒。0：制限なし） | 悪手問題での1回の読みの最長秒数（8）。 | 下げると、遅いパソコンでの長い待ちが減ります（その時間で読める分だけ読みます）。局地戦には効きません。 |
| 地と形勢の探索手数 | 答えのあとの地とおおよその形勢の探索手数。「この局面の最善手」の2手目以降の自分の手は、この2倍を使います（100）。 | 減らすと、地や手順が早く出ますが、粗くなります。 |
| KataGoの準備を待つ最長時間（秒） | KataGo がモデルを読み込むのを待つ秒数（600）。 | KataGo がまだ起動中なのに KentoGo があきらめてしまうとき（遅いパソコンや KataGo の初回起動）は増やします。 |

### 推奨設定

使っているパソコンの種類を選んで「設定」を押すと、判定、地と形勢、棋譜解析の探索手数がそれに
合わせて設定されます。「測る」は、使っているモデルで KataGo の速さを測り、そこから探索手数を
決めます。モデルを変えたら、もう一度押してください。1回の読みが約1.6秒、1局の解析が約2分になる
ように決めます。

| パソコンの種類 | 判定 | 地と形勢 |
| --- | --- | --- |
| GPUなし・古いCPU | 16 | 4 |
| GPUなし・新しめのCPU | 40 | 10 |
| GPUあり・入門〜中級 | 480 | 120 |
| GPUあり・上位 | 1600 | 400 |
| Mac・標準 | 80 | 20 |
| Mac・速い | 160 | 40 |
| Mac・とても速い | 360 | 90 |
| Mac・最速 | 960 | 240 |

変わるのは探索手数だけで、KataGo やモデルの場所はそのままです。

### KataGo棋譜解析（SGFに書き込む）

| 設定 | 働き | 変えると |
| --- | --- | --- |
| 解析する棋譜のフォルダ | 空欄なら、悪手問題と同じ棋譜フォルダ。 | |
| 元の棋譜のバックアップ先 | 書き込む前に棋譜を写す場所（空欄なら棋譜フォルダの `backup`）。 | |
| 高速解析の探索数 | すべての局面を最初に浅く読む探索数（50 未満にはしません）。 | 増やすと悪手を確実に見つけられますが、解析に時間がかかります。 |
| 深く検討する手の探索数 | 問題になりうる手を深く読む探索数（0：「分析時の最大探索手数」と同じ）。 | 増やすと問題の損が正確になりますが、解析に時間がかかります。 |
| 深く検討する手の数 | 深く読む手の数。損の大きい順で、咎め問題用の相手の手は半分まで（6。0：すべて）。 | 減らすと速くなりますが、1局から出る問題が減ります。0 はすべて読むので、時間がかかることがあります。 |
| 失敗した局面をやり直す回数 | KataGo が読めなかった局面を聞き直す回数（2）。 | |

### 出題・判定設定

**出題設定**

| 設定 | 働き | 変えると |
| --- | --- | --- |
| 1日の最大問題数 | 1日に出す問題の数（復習を含む。午前0時にリセット）（20。0：上限なし）。 | 下げると1日の練習が短くなります。復習が多いと、低い上限では新しい問題が出ないことがあります。 |
| 1局の問題数 | 1局から出す問題の最大数。損の大きい順（5）。 | 増やすと、小さめの悪手も問題になります。 |
| 最低損失目数 | この目数以上損した手だけが問題になる（3）。 | 上げると大きな悪手だけ。下げると小さな悪手も（問題が増え、判定も難しくなります）。 |
| 段階出題の目数 | `20,10,5,3` のような区切り。20目以上損した問題を先に出し、次に10目以上、と進みます。その段階の問題をすべて一度正解すると次に進みます（空欄なら使わない。使うときは「1局の問題数」と「最低損失目数」は使いません）。 | 大きな悪手から先に直したいときに使います。 |
| 序盤の除外手数 | この手数までの手は問題にしない（0）。 | 序盤を練習しないなら上げます（たとえば20）。 |
| 待ったの手も出題 | KaTrain の指導碁で待ったをした手も使う（オフ）。 | |
| 勝負が決まったとみなす勝率（%） | 片方の勝率がこれ以上の局面の手は、ほかに問題が足りないときだけ問題にする（99）。 | 下げると、もう勝負がついた対局からの問題が減ります。 |
| 勝負が決まったとみなす目差 | 同じく、この目数を超える差のとき（40）。 | |
| 出題順 | ファイル名順、新しい順、ランダム（ファイル名順）。 | 「新しい順」で、最近の対局から練習します。 |
| 盤を回転・反転 | 問題ごとに、盤をランダムに回転・反転して出す（オフ）。 | オンにすると、盤の見た目で答えを覚えてしまうのを防げます。 |
| 色を入れ替える | 問題ごとに、白黒をランダムに入れ替えて出す（オフ）。 | |
| 出題する問題 | すべての問題、または咎め問題だけ（すべて）。 | |
| 咎め問題：直前の相手の手の損失（目） | 直前の相手の手がこの目数以上損していて…（15） | 下げると、咎め問題が増えます。 |
| 咎め問題：自分の手の損失（目） | …自分の手もこの目数以上損した問題が咎め問題です（5）。相手の悪手を咎めそこねた手です。 | |

**判定設定**

| 設定 | 働き | 変えると |
| --- | --- | --- |
| 小さい問題の境目（目） | 実戦の手の損がこれ未満の問題は小さい問題で、実戦の手より損をしなければ正解（3）。 | |
| 合格ライン（取り戻した割合 0〜1） | それ以外の問題では、損のうちこの割合以上を取り戻せば正解（0.6：60%）。 | 上げると厳しくなります。0.8 なら損の80%を取り戻す必要があります。 |
| 正解とする答えの損の上限（目、0 で上限なし） | それ以外の問題で、正解とする答えの損の上限（0：上限なし）。 | 設定すると（たとえば5）、大きな問題で、まだ大きく損をする手が正解になるのを防げます。 |
| 答えに合わせて、合格ラインと答えの損の上限の変更を提案する | 最近の答えに合わせて、上の2つの値の変更を提案する（オン）。 | オフにすると、自分で決めた値のままです。 |
| 提案に使う直近の問題数 | 提案に使う最近の答えの数。提案の後も、この数だけ解いてから次を考えます（30）。 | |
| 提案する答えの損の上限の段階 | 順に提案する上限（`12,8,5,3`。空欄なら上限を提案しない）。 | |
| 許容幅（目） | 損がこの目数以内の答えは、いつも正解（1）。 | 下げると、惜しい答えに厳しくなります。 |

損は表示どおり（0.1目に丸めて）、取り戻した割合は整数の % で判定します。合格ラインは0.5から0.9まで、
0.1ずつ提案します。損の上限は、最近の答えの3分の1以上が正解で、その平均の損が次の上限より小さく、
80%以上がその上限に収まるときに提案します。

**局地戦の問題（生き死に・境界）の設定**

| 設定 | 働き | 変えると |
| --- | --- | --- |
| 相手 | KataGoの最強の応手、または相手の段級位の人間風の応手（KataGoの最強の応手）。 | 「人間風の応手」にすると、相手がその段級位の人のように打つので、やさしくなり、実戦にも近くなります。 |
| 勝っても不正解にする目数の減り | 最初の局面からの減り（3）。 | 上げるとやさしくなります（少し損をして勝っても正解）。下げると、損をせずに勝つ必要があります。 |

### 復習設定

| 設定 | 働き | 変えると |
| --- | --- | --- |
| 復習の方法 | 忘却曲線（連続正解で終了）、または一度正解したら終了（忘却曲線）。 | 「一度正解したら終了」で、復習が減り、新しい問題が増えます。 |
| 連続正解の回数 | 忘却曲線のとき、何回続けて正解したら問題を終えるか（2。0：復習しない）。間違えた問題は次の日に出て、そのあと3、7、14、30、60日後に出ます。 | 3以上にすると長く覚えていられますが、1問ごとの復習が増えます。 |
| 先に出す問題 | 新しい問題、間違えた問題の復習、または Mix（復習2問→新しい問題1問）（新しい問題）。 | 復習がたまってきたら「間違えた問題の復習」にします。 |

**局地戦の問題（生き死に・境界）の復習設定**

| 設定 | 働き |
| --- | --- |
| 1日の最大問題数 | 1日に出す局地戦の数（復習を含む。午前0時にリセット）（5。0：上限なし）。 |
| 復習の方法 | 忘却曲線、または一度正解したら終了（忘却曲線）。 |
| 連続正解の回数 | 忘却曲線のとき、何回続けて正解したら局地戦を終えるか（2。0：復習しない）。 |
| 先に出す問題 | 新しい問題、間違えた問題の復習、または Mix（復習2問→新しい問題1問）（新しい問題）。 |

働きは、上の悪手問題の復習設定と同じです。

ボタン：

- **今ある問題をすべて対象外にする**：棋譜フォルダのすべての問題を、答えたものとして扱います。
  あとから加えた棋譜の問題は出ます。新しい棋譜から始め直したいときに使います。
- **すべての問題を対象に戻す**：対象外にした問題と完了した問題を、新しい問題としてまた出します。
  答えの記録は残ります。
- **学習履歴を消す**：`~/.kentogo/backups` にバックアップを作ってから、答えの記録を消します。
  そのあとは、初めて使う人と同じように出題されます。
- **局地戦の学習履歴を消す**：局地戦の問題の答えについて、同じことをします。
- **整地練習の履歴を消す**（整地練習がオンのとき）：整地練習の結果について、同じことをします。

## KentoGo が遅いとき

KataGo にかかる時間は、パソコンによって大きく違います。GPU は CPU だけのときの30〜100倍速く読めます。
次の手順を順に試して、十分速くなったらそこで止めてください。

### 手順1：推奨設定を使う

☰ > 「推奨設定」を開いて「測る」を押します（またはパソコンの種類を選んで「設定」を押します）。
1回の読みが約1.6秒、1局の解析が約2分になるように探索手数が決まります。モデルを変えたら、もう一度
「測る」を押してください。

### 手順2：そのパソコンで速いモデルを使う

名前が tf3 で始まるモデルが速いのは、NVIDIA RTX で CUDA 版か TensorRT 版の KataGo を使うときだけです。
それ以外（KaTrain に付いている KataGo、GTX、Radeon、内蔵 GPU、GPU なしのパソコン、Mac）では、
「KataGoモデルファイルの場所」に b18c384nbt（速い）か b28c512nbt（強い）のモデルを使ってください。
たとえば M5 の無印の Mac では、1秒に tf3 は約170、b28 は約420、b18 は約960 局面読みました。そのあと
もう一度「測る」を押します。

### 手順3：遅いところの探索手数を減らす

KataGo の時間は、探索手数にほぼ比例します。探索手数を半分にすると、時間もほぼ半分です。値を半分ずつ
減らして、試してください。探索手数を減らすと読みが粗くなるので、遅いところの値だけを減らします。

| 遅いところ | 変える設定（特に書いていなければ ☰ > 「一般・エンジン設定」） | どのくらい |
| --- | --- | --- |
| 答えのあとの判定（悪手問題） | 「分析時の最大探索手数」 | 半分（たとえば 500 → 250）。または「分析の最大時間」を3か4にします。1問の判定は、最長でその約3倍になります。 |
| 答えのあとの地、形勢、手順 | 「地と形勢の探索手数」 | 半分（たとえば 100 → 50）。「この局面の最善手」の2手目以降の自分の手は、この2倍を使います。 |
| 局地戦での KataGo の応手 | 「分析時の最大探索手数」（「分析の最大時間」は局地戦には効きません） | 半分。 |
| 局地戦のあとの AI 同士の手順（「KataGoへの問い合わせ時間がかかっています。途中で打ち切ります。」と出る） | 「分析時の最大探索手数」 | 結末が出るようになるまで半分ずつ。 |
| 棋譜の解析（1局に数分以上） | ☰ > 「KataGo棋譜解析」の「高速解析の探索数」と「深く検討する手の探索数」 | それぞれ半分。高速解析は50未満にはなりません。「深く検討する手の数」を3にしてもよいです（1局の問題は減ります）。 |

### 手順4：KataGo の起動そのものが遅いとき

KataGo は、KentoGo の起動時にモデルを読み込みます。大きいモデルほど時間がかかります。また KataGo の
版によっては、初回の起動で GPU に合わせた調整をするため、数分かかることがあります（一度だけです）。
2回目の起動からは、あとどのくらいかかるかが表示されます。KataGo がまだ起動中なのに KentoGo が
あきらめてしまうときは、「KataGoの準備を待つ最長時間」を増やします（たとえば 600 → 1200）。

### GPU のないパソコン

GPU がないと、KataGo は1秒に数十局面しか読めません。そのため推奨設定の探索手数は少なく（判定は16か40）、
1局の解析には2分より長くかかります。それでも使えます。棋譜の解析はほかのことをしている間（たとえば
夜の間）に進め、b18c384nbt のモデルを使い、「推奨設定」で「GPUなし・古いCPU」か「GPUなし・新しめの
CPU」を選んでください。

## 練習をやさしく・難しくする

| したいこと | 変える設定 |
| --- | --- |
| 大きな悪手だけを練習する | 「最低損失目数」を上げる（たとえば 3 → 8）、または「段階出題の目数」を使う。 |
| 判定を厳しくする | 「合格ライン」を上げる（0.6 → 0.8）、「正解とする答えの損の上限」を設定する、または提案をオンのままにする（強くなるにつれて KentoGo がラインを上げます）。 |
| 判定をやさしくする | 「合格ライン」を下げる（0.6 → 0.5）、または「許容幅」を上げる。 |
| 1日の練習を短くする | 悪手問題の「1日の最大問題数」と、局地戦の「1日の最大問題数」を下げる。 |
| 復習を増やして長く覚える | 「連続正解の回数」を上げる（2 → 3）。 |
| 局地戦をやさしくする | 「相手」を「相手の段級位の人間風の応手」にし、許容する目数を上げる（3 → 5）。 |
| 盤の見た目で答えを覚えないようにする | 「盤を回転・反転」と「色を入れ替える」をオンにする。 |
